# Лабораторная работа 2



Тема: условия, циклы, структуры.



## Задания



1. Определить, чётное или нечётное введённое число.

2. Функция, которая возвращает "Positive", "Negative" или "Zero".

3. Вывести все числа от 1 до 10 с помощью цикла for.

4. Функция, которая принимает строку и возвращает её длину.

5. Структура Rectangle и метод для вычисления площади прямоугольника.

6. Функция, которая принимает два целых числа и возвращает их среднее значение.



## Как работает



Ввод через bufio, числа парсим через strconv.Atoi.



Для задания 6 использую strings.Fields, чтобы вытащить два числа из одной строки.
