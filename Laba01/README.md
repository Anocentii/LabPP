# Лабораторная работа 1

## Задания
1. Программа выводит текущее время и дату.
2. Создать переменные разных типов (int, float64, string, bool) и вывести их.
3. Использовать краткую форму объявления переменных (:=).
4. Арифметические операции с двумя целыми числами.
5. Функция для вычисления суммы и разности двух чисел с плавающей запятой.
6. Программа вычисляет среднее значение трёх чисел.

## Как работает
Все задания собраны в одной программе и вызываются по очереди в `main`.
Для 6-го задания пользователь вводит три числа, программа парсит их как `float64`
и выводит среднее с точностью до двух знаков.

## Запуск
```bash
go run ./Laba01.gp
```
